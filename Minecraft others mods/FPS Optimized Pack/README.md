# FPS Optimized Pack (Minecraft Bedrock)

A performance resource pack for **Minecraft Bedrock Edition**, aimed at **60+ FPS** on
low-end devices (phones, tablets/iPad, low-end PCs). It does this by removing the most
GPU-expensive parts of vanilla rendering.

## What it does
- **Flat solid-color blocks** — every block texture (~350 of them) is a single flat color, so
  the GPU does almost no texture work.
- **No animated textures** — water, lava, fire, portals, sea lanterns, magma, prismarine,
  campfires, etc. are frozen to a single static frame (no per-tick animation churn).
- **Clear glass** — all glass (plain + 16 stained colors) is fully transparent, so glass
  surfaces cost nothing to draw.
- **Opaque leaves & foliage** — leaves, grass, vines and ferns are fully opaque, avoiding the
  expensive transparency / cutout render path (the "Fancy graphics" cost).
- **No particles** — the particle atlas is fully transparent, so particles render as nothing.
- **Low mipmap levels** for cheaper texture sampling.

## Install
1. Copy `FPS-Optimized-Pack.mcpack` to your device.
2. Open it with Minecraft (double-click / "Open with Minecraft", or import it). It imports into
   **Settings → Storage / Global Resources**.
3. Enable **FPS Optimized Pack** under a world's Resource Packs or in Global Resources, then
   move it to the **top** of the active list.

For best FPS also lower in-game **Render Distance** and turn off **Fancy Graphics / Smooth
Lighting**.

## Rebuilding
The pack is generated by a script (standard-library Python only — no Pillow/ImageMagick):

```bash
python3 build_pack.py
```

This regenerates `FPS-Optimized-Pack/` and repackages `FPS-Optimized-Pack.mcpack`.

### Editing block colors
Open `build_pack.py` and edit the `BLOCKS` dictionary — each entry is a vanilla
`terrain_texture` key mapped to an `(R, G, B, A)` color. Add or change entries, then rerun the
script. Keys that match your game version take effect; unmatched keys are harmless.

## Notes
- `min_engine_version` is set to `1.21.0`. Resource packs are forward-compatible, so it loads on
  newer Bedrock builds too.
- This pack changes **textures only**; it does not change game behavior, so it is safe on
  servers and Realms.
