📱 Terraria: getting mobile players in (crossplay)

      

        Mobile (and console) Terraria speak a different network protocol than PC.
        The plain dedicated server BlockHost runs cannot translate it, so a phone will
        sit on “connecting to session…” forever — even when both are on the exact same
        version. This is a Terraria limitation, not a bug in your server.
      

      
The working fix is a modded server that translates the packets:

      
    
        
  1. Download TShock for your exact Terraria version (1.4.5.6 → TShock 6.1)
            from github.com/Pryaxis/TShock and run it once so it creates its folders.
    2. 
        
  2. Download Crossplay.dll from github.com/Moneylover3246/Crossplay
            and drop it into TShock’s ServerPlugins folder.
    3. 
        
  3. Restart TShock. Mobile joins the same way: Multiplayer → Join via IP →
            … and the port.
    4. 
      

      

        Versions must line up: TShock, the Crossplay plugin, PC and mobile all on the same
        Terraria version. If the plugin hasn’t been rebuilt for the newest version yet, mobile
        crossplay waits on that update. PC-only servers need none of this.
